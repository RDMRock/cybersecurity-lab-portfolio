# Cybersecurity Lab Portfolio

I built this collection from my SFU cybersecurity lab coursework. The work follows findings from discovery through controlled exploitation, explanation, and remediation where the assignment included a fix.

**Best starting points:** [web vulnerability fixes](case-studies/07-web-vulnerabilities-and-remediation.md), [MCP hardening and tests](code/mcp-hardening/README.md), and [Windows investigation](case-studies/03-windows-post-exploitation-and-ai-authorization.md).

## Code and evidence

- [MCP defensive implementation](code/mcp-hardening/README.md): parameterized SQL, bounded file access, and shell-free Git calls, with a self-contained test fixture.
- [Web patch excerpts](code/web-patches/README.md): the routes used in the report, with their dependencies and remaining limitations.
- [MCP code review](code/mcp-review/README.md): proposed replacements, explicitly separate from the deployed patches.
- [Selected screenshots](evidence/README.md): original captures showing post-patch behavior.
- [Coverage and source notes](docs/coverage.md): what was reviewed and how evidence is described.

The reports support practical experience with Kali Linux, Windows, Nmap, Nessus, Metasploit, Wireshark, Bettercap, mitmproxy, Docker, Python, JavaScript, SQLite, Flask, and FastMCP. The examples are academic lab work, not production SOC experience.

## Context and attribution

Course applications were intentionally vulnerable teaching systems. I tested the supplied applications and my designated lab VMs. Interception examples describe traffic generated by my own lab browser. Simulation results use controlled accounts and dummy data.

This public collection contains edited case studies and selected code. Instructor handouts, lecture slides, VM images, executable payloads, memory dumps, credential databases, session tokens, student numbers, and unreviewed screenshots are excluded.

The reports record AI assistance with formatting, research, analysis, code, or guided lab steps to varying degrees. This portfolio was also organized and edited with AI assistance. Specific implementation and validation claims are tied to the available source reports and code, rather than implying that every line was written without assistance.

See [attribution](docs/attribution.md) and [validation](docs/validation.md). My [cryptography collection](https://github.com/RDMRock/applied-cryptography-labs) and [home-lab journal](https://github.com/RDMRock/home-cybersecurity-lab) cover related work.
